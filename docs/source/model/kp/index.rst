关键点检测
=================================

在 **关键点检测** 中，模型通过学习物体的外轮廓及其关键点的位置信息，来识别物体的类别，并定位物体的方向、位置等信息。

模型选择情景
---------------------------------
**关键点检测** 模型可以用以检测图像中的一个或多个不同物体的数量及位置。

与 **分割实例** 模型相似，**关键点检测** 模型可以对一个或多个物体进行精确定位。与 **分割实例** 模型不同的是，**关键点检测** 模型不需要对物体进行分割，而是通过检测物体的关键点来定位物体，从而获得对于规则对称图形更好的识别效果。
