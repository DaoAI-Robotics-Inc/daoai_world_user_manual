模型体验
---------------

在这里，您可以尝试DaoAI 为您预训练的模型。

.. image:: images/playg.png
    :scale: 60%
    :align: center

选择预训练模型，目前只支持OCR。

然后上传图片，或者使用DaoAI数据集里的图片进行模型预测。

.. image:: images/ocr.png
    :scale: 70%
    :align: center

然后您就可以得到模型预测后的效果。

如果您对模型的效果满意，您可以点击下载此模型，并在本地，或者 **DaoAI InspecTRA 2.24.3.0** 以及 **DaoAI VisionPilot 2.24.4.0** 中使用。
