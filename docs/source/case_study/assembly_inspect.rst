组装检测
-------------

在这个项目中 我们需要检测以下工件是否正确的组装：是否有全部的螺丝：4个

    .. image:: images/shanghengliang.png
        :scale: 100%


分析图片后 我们可以知道：

1. 图像中有若干螺丝孔，有些没有安装螺丝，需要检测安装螺丝的有无或者数量

对象检测模型可以满足我们的需求。

    .. image:: images/shanghengliang_label.png
        :scale: 70%
        
使用边界框框出没有安装螺丝的孔。

训练并部署后，我们就可以轻松识别是否有为安装的孔，以及有几个螺丝未安装。
