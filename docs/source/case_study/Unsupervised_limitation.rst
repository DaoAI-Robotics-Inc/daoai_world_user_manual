非监督缺陷分割：纸桶缺陷检测
--------------------------


需求：
**********************

        - 客户期望对印刷纸筒实施瑕疵检测，然而，鉴于瑕疵类型繁多，收集瑕疵图像面临诸多挑战。基于此，客户倾向于采用无监督模型来执行这一检测任务。
        - 检测对象：印刷纸筒的整体线扫图像。
        - 检测内容：针对纸筒表面的压痕、破损、脏污、露白等瑕疵展开检测。
        - 检测种类：目前涉及的瑕疵类型已超过五种。

        .. image:: images/纸桶缺陷图.png
                :scale: 50%

数据情况说明
**********************

        - 数据集中，合格（OK）与不合格（NG）样本并非源自同一批次，二者在种类、表面特性、光照条件以及采集设备等方面存在显著差异，这给分析的准确性带来了挑战，因此，对数据进行预处理显得尤为必要。

        .. image:: images/纸桶.png
                :scale: 100%

原因分析：
**********************

        - 数据预处理的必要性：由于数据批次不同，直接使用可能导致模型学习到批次间的非缺陷特征，从而影响检测准确性。
        - 分辨率问题：在模型训练时、平台会固定将图片resize到224像素，如果原始图像是512像素，resize可能导致小缺陷看不清。因此，需要在预处理阶段将图像resize到512像素，以保留缺陷细节。

解决方案：
**********************

        - 数据清理与筛选：对OK和NG数据进行清理，分别从两个文件中选取近似同一批次的数据，确保印刷内容和纸张颜色的一致性。
        - 具体步骤：筛选原始数据，根据纸张颜色和印刷内容进行分类。切分OK和NG数据，从 NG 数据中挑选与 OK 数据印刷内容和纸张颜色相近的部分，进行进一步区分。


结论：
**********************

鉴于精确的缺陷识别需求以及数据预处理的复杂性，非监督模型在这种情况下可能无法达到预期效果。



非监督缺陷分割：不锈钢盆缺陷检测
--------------------------

需求：
**********************

        - 检测目标：检测不锈钢盆中是否存在生锈（淡黄色区域为锈迹）、米饭颗粒、脏污（清晰且大范围的污渍）以及大的水印。
        - 注意事项：物体中心的暗黑色区域不进行检测（由于打光设备造成的阴影区域）。

        .. image:: images/不锈钢盆.png
                :scale: 50%


分析数据：
**********************

        - 数据预处理：鉴于原始数据质量参差不齐，我们首先对数据进行分割和提取操作，确保物体在图片中居中，背景干净无干扰，从而为模型训练提供更优质的数据基础。

数据处理的优势：
**********************

        - 增强特征学习：帮助模型更轻松地捕捉到关键特征。
        - 减少干扰：去除无关信息，避免对模型造成误导。
        - 提高检测精度：规范化的数据有助于模型更准确地定位和识别缺陷。
        - 简化模型训练：降低数据复杂度，使训练过程更高效。

非监督缺陷测试结果：
**********************

        - 测试表现：初步测试结果显示，模型的识别错误率较高，整体表现未能达到预期。
        
        .. image:: images/非监督可视化失败.png
                :scale: 50%

测试结果分析：
**********************

        - 数据定义问题：在需求定义阶段，正常数据与异常数据之间存在一些较为明显的缺陷，具体表现为定义不够清晰，且两者之间的区分不够明显。

        .. image:: images/康熹.png
                :scale: 50%
解决办法：
**********************

        - 明确数据样本：向客户索要明确的正常样本和异常样本数据，确保数据定义清晰准确。
        - 优化检测策略：在检测过程中，对大缺陷进行检测，同时对小缺陷也进行标记，随后运用后处理手段将小缺陷过滤掉，以提高检测的准确性。
        - 更换模型：将非监督缺陷分割模型更换为“监督缺陷分割模型”，测试结果显示，该模型能够高效且精准地识别出缺陷。

        .. image:: images/监督缺陷可视化成功.png
                :scale: 50%

结论：
**********************

        - 环境适应性：由于正常和异常数据区分不明显，非监督模型在这种环境下难以有效工作。通过更换为监督缺陷分割模型，显著提升了检测的准确性和可靠性。


非监督缺陷分割：袜子缺陷检测
--------------------------

**********************

        - 检测目标：精准识别袜子的多种缺陷，包括缺纱、破洞、色线、线头、脏污等。
        - 数据集情况：数据集涵盖朝向左和朝向右的袜子，共7种类型。需构建单一模型以识别各类袜子的缺陷。

问题描述：
**********************

        - 数据问题：袜子种类繁多，数据表面存在杂质，软物折痕明显，且背景颜色与袜子颜色高度相似，这些因素共同作用，严重影响了数据的一致性，给模型训练带来了巨大挑战。

非监督缺陷测试结果：
**********************

        - 测试表现：初步测试结果显示，模型的识别错误率居高不下，整体表现不尽如人意。
        
        .. image:: images/袜子非监督可视化失败.png
                :scale: 50%

测试结果分析：
**********************

        - 背景干扰：背景环境噪音较大，干扰了模型对袜子缺陷的准确识别。因此，去除背景干扰成为提升模型效果的关键步骤。
        - 左右袜子处理：左右袜子存在垂直不对称性，导致同一区域出现两种数据分布，这无疑增加了模型的学习难度。将左右袜子分开处理，有助于保持数据的一致性，从而提升模型的识别性能。

        .. image:: images/袜子处理后数据.png
                :scale: 70%

非监督缺陷数据处理后测试结果：
**********************

        - 处理后表现：尽管进行了数据处理，但测试结果依然显示模型存在识别错误，表明当前非监督模型在处理这类复杂数据时仍面临较大挑战。

        .. image:: images/袜子非监督处理后数据可视化失败.png
                :scale: 70%

结论：
**********************
        - 由于袜子种类繁多，需要用一个模型识别所有种类袜子的缺陷，非监督模型在这种情况下难以实现有效的缺陷检测。
