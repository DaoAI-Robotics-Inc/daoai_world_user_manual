DWSDK C# 项目配置
------------------------

项目配置
~~~~~~~~~~~~

    点击C#项目中的添加reference
        
        .. image:: images/add_ref.png
            :scale: 100%

    点击浏览，然后浏览解压目录下的bin文件夹内的 ``dl_sdk_net.dll`` 文件，勾选后，点击OK。
        
        .. image:: images/browse_dll.png
            :scale: 100%

    点击assembly，然后搜索 ``system.drawing`` 勾选后，点击OK。
        
        .. image:: images/browse_assembly.png
            :scale: 100%
