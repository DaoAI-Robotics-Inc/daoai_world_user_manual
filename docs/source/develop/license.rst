
软件许可证
------------------

使用 DaoAI World SDK 需要我们提供的 USB 加密狗，使用时需要插到部署的机器上即可。

插上加密狗后，运行sdk时，您会看到 Standard SDK license: OK 和 Unsupervised Model SDK license: OK 


    .. image:: images/unsupervised_key.png
        :scale: 80%  

如果没有加密狗 或者没有正确授权的加密狗，则会看到 Standard SDK license: OK 或 Unsupervised Model SDK license: Invalid

或者 弹窗报错。

    .. image:: images/ldk_failed.png
        :scale: 80%
