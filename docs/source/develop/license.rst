Software License
------------------

DW_SDK requires an official software license authorized by `DaoAI` to use. Please contact your support engineer or customer representative to obtain the license. You will need to provide your computer information to `DaoAI`'s staff:

    - Double-click the ``DW_SDK`` shortcut on the desktop to open the License Management Center.

    .. image:: images/dlsk_installer_icon.png
        :scale: 80%   

    - After opening the License Management Center, you will see the following interface.

    .. image:: images/dlsk_installer_license_manager_gui.png
        :scale: 80%   

    - Click ``File`` and then select ``Computer Information``.

    .. image:: images/dlsk_installer_machineid.png
        :scale: 80%  

    - Here, you can view your computer's name and machine code. Click ``Copy Computer ID`` to copy the machine code and send it to `DaoAI`'s staff for authorization.

    .. image:: images/dlsk_installer_copy_id.png
        :scale: 80%  

    .. warning::

        The `license_manager.exe` was updated in version 2.24.7 and is not compatible with the version 2.24.6 license_manager. Although the license files are shared, you must replace the old `license_manager.exe` to use the SDK with version 2.24.7. |br|

        The `license_manager` can be found in the `bin` folder within the <SDK installation directory>.

Online Authorization (Requires Internet Connection)
~~~~~~~~~~~~~~~~

Once you have obtained the license, you can add it directly through the interface:

    - Click ``File`` and select ``Add Software License``.

    .. image:: images/dlsk_installer_add_online_license.png
        :scale: 80%  

    - Enter the valid license obtained from `DaoAI`'s staff. The license is a 32-character alphanumeric activation code, which you can copy and paste into the following interface.

    .. image:: images/dlsk_installer_add_online_license_1.png
        :scale: 80%  

    - Click ``Check`` to verify the license information.

    .. image:: images/dlsk_installer_online_license_check.png
        :scale: 80%  

    - The manager will confirm the license is activated and ready for use.

    .. image:: images/dlsk_installer_online_license_check_good.png
        :scale: 80%  

    .. note::
        Online authorization requires the computer to be connected to the internet.

Offline License
~~~~~~~~~~~~~~

Due to environmental limitations, some users cannot connect their devices to the internet. In such cases, `DaoAI`'s staff will provide you with an offline license. After obtaining the license, you can add it directly via the interface:

    - Click ``File`` and select ``Import Offline License File``.

    .. image:: images/dlsk_installer_add_offline_license.png
        :scale: 80%  

    - Choose the offline license file provided by `DaoAI`'s staff.

    .. image:: images/dlsk_installer_select_offline_license.png
        :scale: 80%  

    - The manager will confirm that the license is activated and ready for use.

    .. image:: images/dlsk_installer_offline_license_check.png
        :scale: 80%
