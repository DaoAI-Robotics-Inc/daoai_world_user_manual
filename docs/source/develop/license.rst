Software License
------------------

Using the DaoAI World SDK requires a USB dongle provided by us, which must be plugged into the deployment machine.

Once the dongle is inserted, when running the SDK, you will see:
Standard SDK license: OK
Unsupervised Model SDK license: OK

    .. image:: images/unsupervised_key.png
        :scale: 80%

If the dongle is not present or is not properly authorized, you will see:
Standard SDK license: OK
Unsupervised Model SDK license: Invalid

Or a popup error will appear.

    .. image:: images/ldk_failed.png
        :scale: 80%
