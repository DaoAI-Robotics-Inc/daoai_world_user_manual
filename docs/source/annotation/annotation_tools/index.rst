标注工具
========

用于在计算机视觉项目中标注图像。

DaoAI_World提供了一个快速、稳健的界面，通过它你可以对图像进行标注。

DaoAI_World能够执行实例分割和关键点检测项目。因此，我们将介绍实例分割工具和关键点检测工具。

.. tabs::
    .. tab:: 实例分割工具

        1. **拖动工具**：
            * 快捷键：空格
            * 平移图像或选择/重新定位注释。

        2. **多边形工具**：
            * 快捷键：P
            * 自由绘制注释，以获得更精确的形状。

        3. **智能多边形**：
            * 快捷键：S
            * 使用智能助手绘制多边形。点击对象的中心，然后继续点击以添加或减去区域。

        4. **标签辅助**
            * 快捷键：Ctrl + B
            * 使用 DaoAI Train 模型的预测作为起点。

        5. **重复上一个**
            * 快捷键：Ctrl + Y
            * 应用上一个标注的所有注释（对于视频帧很有用）。

        6. **撤销**
            * 快捷键：Ctrl + Z
            * 撤销上一个操作。

        7. **重做**
            * 快捷键：Ctrl + Shift + Z
            * 重做上一个操作。

        8. **标记为空**
            * 快捷键：Ctrl + M
            * 空图像是没有感兴趣的对象的图像。未注释的图像正在等待人工标注。
