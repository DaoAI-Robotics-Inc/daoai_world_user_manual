关键点标注
============


您可以从DaoAI_World的"标注"或"数据集"界面选择图像来访问标注界面。 

在标注界面的右侧，您可以看到工具栏。工具栏中有许多可以用于标注外轮廓与关键点的工具。

在本节中我们将对标注关键点的工具进行介绍


.. tabs::

    .. tab:: **注意事项**

        .. warning:: 1. 标注的关键点必须要在外轮廓(分割区域)内。标记在外轮廓(分割区域)外的关键点是不起作用的。此时您所标记的点显示未绿色，同时悬浮栏会出现提示。

            .. image:: Images/bupipei.png
                :width: 600
                :align: center
        
        .. warning:: 2. 由于外轮廓(分割区域)与其内部的关键点是相对应的关系，因此如果您传入了在其他软件中标注带有外轮廓(分割区域)标注数据的图像再在DaoAI_World中标注关键点，则关键点
            无法与所在的外轮廓(分割区域)相对应，从而可能造成无法训练以及训练效果差等影响。

        .. warning:: 3. 如果您标注了一个外轮廓(分割区域)后又在外轮廓(分割区域)内标记了关键点后，如果您对外轮廓不满意，则您在删除外轮廓(分割区域)的同时也需要将所属的关键点一起删除。



    .. tab:: **标记关键点工具**

        关键点是为了更好的帮助机器认识所需要物体的信息而创建。如果您需要进行关键点标注则需要在"创建新项目"界面项目类型中选择 **关键点** 选项。


        .. image:: Images/task_key.png
            :width: 400
            :align: center


        同样在标注界面右侧栏中您可以看到 **标记关键点工具** 及一个十字准线。

        标记关键点工具允许您创建感兴趣的关键点。在此模式下，您可以看到您的光标变成一个十字准线，帮助您更精准的点击您所需要的点。

        单击您所需要的点后，在类别选择器中选择其标签。同时如果您标记错误或类别选择错误，可以使用撤销指令，或使用拖拽工具点击该点修改。

        .. image:: Images/key_tools.png
            :width: 400
            :align: center
