分割标注（外轮廓标注）
=======================


您可以从DaoAI_World的"标注"或"数据集"界面选择图像来访问标注界面。 

在标注界面的右侧，您可以看到工具栏。工具栏中有许多可以用于标注外轮廓与关键点的工具。

在本节中我们将对标注外轮廓的工具进行介绍

.. tabs::

    .. tab:: **多边形工具**
        多边形注释工具允许您绘制新的多边形标注。在此模式下，您可以看到一个十字准线，帮助您确定从哪里开始绘制。

        单击感兴趣对象周围的图像以创建封闭的多边形注释，然后使用类选择器选择其标签。

        .. image:: Images/duobianxing.png
            :width: 400
            :align: center



    .. tab:: **智能多边形工具**

        智能多边形工具通过调用人工智能大模型帮助您更快进行外轮廓标注。

        在此模式下，当您点击一个尚未标注的物体时，您将在您鼠标左键点击的地方看到一个绿点，同时在周围会出现一片与其他地方颜色不同的区域，这就是人工智能认为的
        感兴趣区域。如果您发现人工智能认为的感兴趣区域与您实际需要的区域不相符时，您可以使用鼠标右键点击您不感兴趣的区域，此时点击的区域会出现红点同时此区域
        也会变成不感兴趣区域。


        .. image:: Images/smart_annotation.png
            :width: 800
            :align: center

        智能多边形工具对于边界分明，图像清晰，特征明显的标注任务十分有利，在大多是时候能够起到提高标注效率的功能，但是在某些特殊情况可能还是需要使用多边形工具
        进行标注。

    .. tab:: **标签助手**

        标签助手使用DaoAI_World 训练过的模型进行预测。

        .. image:: Images/biaoqianzhushou.png
            :width: 400
            :align: center   

        在此模式下，首先您需要有最少一个已经训练好的模型。点击 **标签助手** 选取对应的项目与相应的模型，点击继续便可以进行预测。标注的效果好坏取决于模型的质量。

        .. image:: Images/moxing.png
            :width: 600
            :align: center
