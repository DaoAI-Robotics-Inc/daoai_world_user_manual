开始一个项目
==============================

    .. contents::
        :local:


在 **DaoAI World** 中一个项目理应包含需要被标注的图片。并且所有同类型的标注图片只存在同个项目内。图像被标注完成后，可以用它们可以生成一个包含时间和标注内容的训练集，并可以用你选择的配置进行扩充和处理。








创建项目
-----------------

    首先,进入到DaoAi World首页,然后,点击"创建新项目":

        .. image:: images/create_project.png
            :width: 800
            :align: center

    在弹出的窗口中填写项目的相关信息：
    1. 选择项目类型：目前支持的项目类型分为：实力分割，关键点检测，异常检测，分类检测，物体检测
    2. 查看更多项目类型
    3. 添加项目名称，此名称应具有唯一性，同一个账户中不应出现相同命名的项目
    4. 继续添加设定项目信息

    在新的窗口中设定项目的类别标签信息：
        .. image:: images/create_project1.png
            :width: 800
            :align: center

    在这里，根据所拥有的数据集不同，可以选择在 **1** 处添加数据的类别标签信息，或点击 **跳过并创建空项目** 以使用已有类别标签的数据集，或随后再添加类别标签信息。完成类别信息添加后，点击 **创建项目** 以完成项目的创建。

    类别标签的选择与标注方法与项目的类型相关，具体类别标签选择与标注方法请参阅各项目类型的文档内容：

上传数据
-----------------

    在项目创建成功之后，可以通过 **选择文件** 或 **选择文件夹** 的方式上传图片数据。上传的图片数据将会被添加到项目中，以供后续的标注工作。

        .. image:: images/upload_folder.png
            :width: 800
            :align: center

    数据集支持.jpg和.png 格式的图片文件, 以及.json格式的标注文件。如果上传的数据中包含.json格式的标注文件，系统会自动读取标注文件中的标注信息，并将其显示在标注信息中。您可以在此查看被识别到的标注信息是否正确，用以确保图片的标注没有出现错误。
    
        .. image:: images/label_recog.png
            :width: 800
            :align: center

        .. warning:: 
            请注意，由于系统限制，单词上传图片建议小于1000张，单次上传图片数量过多可能会导致上传失败。
