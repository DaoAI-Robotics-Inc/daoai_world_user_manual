分类检测
==================================

标注方法
----------------------------------

**分类检测** 与其他模型不同，它不需要对图片内部信息进行标注，只需要对图片整体进行标注。在进行标注时，可以单张标注，也可以进行批量标注。

进行单张标注时，打开一张未标注图片，选择分类标签，然后点击 **保存** 即可完成对单张图片的标注。

    .. image:: Images/classAnno0.png
        :width: 600
        :align: center

如果想要同时标注多张图片，点击上方的图集标签进入图集模式。

    .. image:: Images/classAnno1.png
        :width: 600
        :align: center

在图集模式下，同时选择多张图片，随后点击 **批量标注**，即可将全部被选图片标注为同一分类。

    .. image:: Images/classAnno2.png
        :width: 600
        :align: center

同理，也可以通过分批上传图片，然后在同一数据集内使用全选及批量标注功能来快速标注大量数据。

分类检测模型标注注意
----------------------------------

1. **分类检测** 的标注目标为整张图片，而非图片中的某一单一物体。

2. **分类检测** 的数据集中，每张图片应只包含目标物体，以减少其他物体的影响。

3. 可以通过预处理中划定感兴趣区域来减少图片中的其他物体对模型的影响。
