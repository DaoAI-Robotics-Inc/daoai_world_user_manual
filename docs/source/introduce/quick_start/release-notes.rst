2.24.7.0 版本更新说明：
--------------------------

- 全新的创建项目界面
- 新增了演示项目，可以使用演示项目，并在工作空间中获得指导
- 新增了图像显示设置，能够帮助用户在标注中调整图像设置，提高标注效率
- 新增了实时显示识别结果和标注结果比较，更好的分辨识别和标注结果的区别
- 新增了定位模型，用于检测图像中的对象并标记它们的位置，适用于机器人装配等多种工业应用
- 新增了错漏装检测模型，根据与标准图像对比，检测图像中零件的安装情况。常用与零件的错装和漏装检测
- 新增了分类模型在标注时，能够标注“背景”标签，表示图中无其他物件，仅有背景
- 新增了OCR模型能够专注于文本识别项目的语言，用户能够选择所需识别的语言，提高效率和准确率
- 新增了定义决策标准，可以选择最符合您模型判断要求的决策标准，以便在模型推理时更好地过滤检测结果
- 新增了最大增强大小选项，可以调整图像增强的次数，以创建更多的训练样本。更大的版本训练时间更长，但通常会获得更好的模型性能
- 新增了从上一个记录点开始训练，推荐从之前的训练运行中开始，以加快训练速度并提高准确性。如果您已经在此项目上成功训练了模型，这个选项是最好的
- 新增了模型推理显示，显示推理时间和训练的显卡类型，帮助用户更好的了解识别速度
