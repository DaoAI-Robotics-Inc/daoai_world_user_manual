2.24.5.0 版本更新说明：
--------------------------

- 新增了训练手动提前停止功能
- 新增了OCR项目的智能标注
- 健康检查发现错误时，会有更详细的错误说明
- 上传文件添加了jpg支持， 目前支持的格式有png jpeg jpg
- 新增了标注时，在顶部输入页数跳转的功能
- OCR模型支持4点矩形标注，可以更好的标注弯曲的字体
- 新增标注空时，在详情和概略视图中显示标注为空的图标
- 标注无缺陷时，在详情和概略视图中显示无缺陷的图标
- 优化了图片加载速度
- 新增了所有模型的默认Resize预处理步骤
- 新增从其它项目中导入数据集的功能
- 优化了健康检查的速度
- 新增了模型训练页面的预计训练时间
- 新增了导出模型时的版本号信息
