发布说明
============

.. contents:: 
    :local:

2.25.2.0 版本更新说明：
--------------------------


- 更新了监督缺陷分割的超高分辨率训练模式，最大可支持将图片resize到 3584*3584 分辨率下训练。
- 更新了非监督缺陷分割的像素级训练: 现在仅需一张正常样本就可以训练并完美检测出未知的缺陷; 移除了最大300张数据集的限制;
- 移除了非监督的全图模式，现在都是区域模式，如果需要全图检测，可以将监测区域画为全图。


2.25.1.0 版本更新说明：
--------------------------


- 更新了 SDK 加密方式，现在所有的SDK都需要硬件加密狗才可以使用
- 修复了部分模型训练失败的错误
- 新增了 本地HTTP推理 C# 语言的支持
