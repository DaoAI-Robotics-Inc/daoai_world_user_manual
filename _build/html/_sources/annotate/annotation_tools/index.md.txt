# Annotation Tools
*Annotate images for use in your computer vision projects.*

DaoAI_World Annotate provides a fast, robust interface through which you can annotate images.

DaoAI_World Instance can do Instance Segmentation and Keypoint Detection project.Thus, we will introduce Instance Segmentation's Tools and Keypoint Detection's Tools.

## Instance Segmentation's Tools

1. **Drag Tool** :
    * keyboard shortcuts: Space
    * Pan the image or select reposition annotations.

2. **Polygon Tool** :
    * keyboard shortcuts: P
    * Freeform draw annotations for more precise shapes.

3. **Smart Polygon** :
    * keyboard shortcuts: S
    * Use an intelligent assistant to draw your polygons. Click the center of your object, then keep clicking to add or subtract areas.

4. **Label Assist**
    * keyboard shortcuts: Ctrl + B
    * Use the predictions from a DaoAI Train model as a starting point.

5. **Repeat Prev**
    * keyboard shortcuts: Ctrl + Y
    * Applies all of the annotations from the last image you annotated (Useful for video frames.)

6. **Undo**
    * keyboard shortcuts: Ctrl + Z
    * Undo the previous action.

7. **Redo**
    * keyboard shortcuts: Ctrl + Shift + Z
    * Redo the previous action.

8. **Mark Null**
    * keyboard shortcuts: Ctrl + M
    * A null image is one with no objects of interest present. An unannotated image is waiting for a human to annotate it.
